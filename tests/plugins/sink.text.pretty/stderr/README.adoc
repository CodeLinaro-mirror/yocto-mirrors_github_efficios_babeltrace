= `sink.text.pretty` standard error tests
Philippe Proulx
:toc: left

This directory holds data-driven tests which verify that a
`sink.text.pretty` component writes the expected messages to the
standard error stream for a given CTF trace.

Each test file targets a single, specific standard error behaviour
rather than bundling many cases into one shared trace. When a test
fails, the narrow scope of the file makes the cause of the failure
immediately obvious: the metadata stream, the data stream, the
`sink.text.pretty` initialization parameters, and the expected standard
error stream pattern all describe just the one behaviour under test.

Each `.mctf` file represents a single pytest test. `conftest.py`
collects and runs those files. You can "`run`" a single one if you
want:

----
$ bt-pytest disc-events-clk-count-1.mctf
----

== File naming

pytest collects every file with the `.mctf` extension in this
directory.

== File format

Each `.mctf` file is a moultipart file (see `moultipart.py` in the
source tree) containing the following parts, separated by `---` lines:

. **Metadata stream**, always named `metadata`:
+
--
CTF{nbsp}1.8::
    A complete TSDL metadata stream (the part content goes directly
    into the materialized `metadata` file).

CTF{nbsp}2::
    A JSON array of metadata fragments.
+
`mctf.py` converts it into the corresponding JSON text sequence
when materializing the `metadata` file.
--

. **Data streams**, written as
  https://github.com/efficios/normand[Normand] text.
+
This is 100% of the data stream(s) to write.

. **Component initialization parameters** (optional), always named `@params`:
+
A list of `KEY=VAL` lines, one per initialization parameter, passed to
the `sink.text.pretty` component.
+
The value `yes` becomes true, the value `no` becomes false, and any
other value is considered to be a string.
+
`conftest.py` always sets `color=never`. Initialization parameters
listed here are merged on top of that default.

. **Expected standard error pattern**, always named `@stderr-re`:
+
A Python regular expression which must match the _entire_ textual
content of the standard error which the `sink.text.pretty`
component writes.
+
Leading and trailing whitespaces are stripped from both sides before
the match.

== How a test runs

For each collected `.mctf` file, `_StderrMctfItem.runtest()`:

. Materializes the trace into a temporary directory using
  `mctf.generate()`. This produces:
+
--
* One `metadata` file.
* One or more data stream files.
--

. Reads the `@params` part (if any) and merges it with the default
  parameters.

. Reads the `@stderr-re` part to obtain the expected standard error
  pattern.

. Feeds the materialized trace directory into a graph made of
  `src.ctf.fs` and `sink.text.pretty`, capturing the contents written
  by the latter to the standard error.
+
The `sink.text.pretty` component runs with the warning log level so that
it emits warning messages to the standard error.

. Asserts that the captured standard error fully matches the
  `@stderr-re` regular expression. If it doesn't, the test fails.

On a mismatch, the test shows the file path, the expected pattern, and
the actual standard error.
